## 🔬 Research & Publication

### Predicting Depression Through Social Media Behaviour: Integrating Behavioural Features and Hybrid Methodologies

**Research area:** Machine Learning, Behavioural Analysis and Mental Health

**Research affiliation:** Amrita Vishwa Vidyapeetham  
**Research venue:** MIKE 2026 — Mining Intelligence and Knowledge Exploration

My first-author research investigates the use of social media behavioural features and machine learning methodologies for depression prediction.

The study compares supervised classification models and unsupervised clustering approaches to evaluate predictive performance and explore behavioural patterns.

**Classification models evaluated**

| Model | Accuracy | Precision | Recall | F1-Score |
|---|---:|---:|---:|---:|
| K-Nearest Neighbours (KNN) | 98% | 98% | 97% | 98% |
| Support Vector Machine (SVM) | 95% | 98% | 92% | 95% |
| Naive Bayes | 94% | 98% | 90% | 94% |
| ID3 Decision Tree | 91% | 98% | 84% | 90% |

**Clustering evaluation**

| Metric | K-Means | K-Medoids |
|---|---:|---:|
| Silhouette Score | 0.347 | 0.0915 |
| Davies-Bouldin Index | 1.164 | 2.8817 |
| Calinski-Harabasz Index | 283.229 | 52.8902 |

KNN achieved the highest classification accuracy in the reported experiments. K-Means showed better clustering quality across the three reported internal evaluation metrics.

**Technologies:** Python • Pandas • Scikit-learn • Machine Learning • Data Analysis
